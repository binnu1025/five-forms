# 五表活動協作系統

活動工作組的六表、人員權限與物資借還管理網站原型。

## 本版內容

- 活動總覽、今日流程與表單完成狀態
- 六表：人員組織、工作進度、工作清單、當日流程、預算、物資借用
- 依角色展示預算：組長僅能處理本組預算；主辦人與會長才能看到總預算
- 雁群／人員關鍵字搜尋與活動角色概念
- 物資借出、部分歸還、待歸位、照片上傳預覽與組長待處理提示
- 歷史活動搜尋與複製介面
- 響應式桌面／手機版面

## 執行

這是無建置步驟的靜態原型，直接開啟 `index.html`，或用任一靜態 HTTP server 啟動。

```powershell
python -m http.server 4173
```

## 後續串接

目前資料為前端示範資料。正式版將加入 Gmail 登入、活動白名單、Google Sheet 資料層、Google Drive 照片上傳，以及權限與異動紀錄。原始 Google Sheet 與 Drive 資料夾不應公開分享給一般組員，所有資料須由後端依登入者角色過濾。
