# 五表活動協作系統

目前版本：`v1.08`

- 頁面固定聚焦本次活動；歷史活動收進右上角／底部「更多」漢堡選單。
- 工作進度改為依討論日期保存的 Asana 精簡版逐組紀錄。
- 活動當天會自動把個人現場工作置頂。
- 手機人力表改為總領導與各工作組直列名單，桌機仍保留矩陣總表。

版本依序使用 `v1.01` 至 `v1.99`，下一個主要版本從 `v2.00` 開始。

活動工作組的六表、人員權限與物資借還管理網站原型。

## 本版內容

- 活動總覽、今日流程與表單完成狀態
- 六表：人員組織、工作進度、工作清單、當日流程、預算、物資借用
- 依角色展示預算：組長僅能處理本組預算；主辦人與會長才能看到總預算
- 雁群／人員關鍵字搜尋與活動角色概念
- 物資借出、部分歸還、待歸位、照片上傳預覽與組長待處理提示
- 歷史活動搜尋與複製介面
- 響應式桌面／手機版面
- 細流可按時段展開，同時查看十個工作組的當下任務
- 每組皆可新增組員，物資可拍照、補上照片並更新歸還狀態
- 個人首頁優先顯示當下任務、待處理物資與準備度
- 細流提供全場、我的與單組三種檢視模式
- 歷史活動可進入查看摘要與當時紀錄
- 預算採直接登錄流程，無審核與分攤
- 指派成員時可從雁群分組人員庫下拉選擇，並自動帶入 Gmail

## 執行

這是無建置步驟的靜態原型，直接開啟 `index.html`，或用任一靜態 HTTP server 啟動。

```powershell
python -m http.server 4173
```

## 後續串接

目前資料為前端示範資料。正式版將加入 Gmail 登入、活動白名單、Google Sheet 資料層、Google Drive 照片上傳，以及權限與異動紀錄。原始 Google Sheet 與 Drive 資料夾不應公開分享給一般組員，所有資料須由後端依登入者角色過濾。
